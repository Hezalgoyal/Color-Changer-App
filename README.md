Color Changer App

A simple Python GUI application made using Tkinter.
It allows the user to change the background color of the window by clicking different buttons.

Features
- Change the background color to Red
- Change the background color to Green
- Change the background color to Blue
- Change the background color to Yellow
- Change the background color to White
- Simple and user-friendly interface
  
Technologies Used
- Python
- Tkinter
  
How to Run
1. Make sure Python is installed on your computer.
2. Save the program as color_changer.py.
3. Open the terminal or command prompt.
4. Run the program using:
   python color_changer.py
   
How It Works
The program creates a Tkinter window with buttons for different colors.

When a button is clicked, the change_background() function changes the background color of the main window.
